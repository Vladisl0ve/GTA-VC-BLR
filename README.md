# GTA GXT Editor

Сучасны Windows-рэдактар тэкставых рэсурсаў GTA III і GTA: Vice City. Праект
адаптуецца для працы над беларускім перакладам.

## Тэхналогіі

- .NET 10 LTS і C# 14;
- WPF/XAML з сістэмнай тэмай Fluent;
- MVVM на базе `CommunityToolkit.Mvvm` 8.4.2;
- MSTest 4.3.2 і Microsoft Testing Platform;
- спасылкавыя тыпы, якія дапускаюць `null`, аналізатары .NET і праект у стылі SDK.

## Распрацоўка

Патрабуецца .NET SDK 10.0.302 або навейшы патч-рэліз галіны 10.0.

```powershell
dotnet restore "GTA GXT Editor.slnx"
dotnet build "GTA GXT Editor.slnx" --configuration Release
dotnet test "GTA GXT Editor.slnx" --configuration Release
dotnet run --project "GTA GXT Editor.csproj"
```

Праграма счытвае і запісвае GXT-файлы GTA III/Vice City, падтрымлівае ўбудаваныя і
карыстальніцкія табліцы сімвалаў, пошук, дадаванне, рэдагаванне, выдаленне і
імпарт адсутных ключоў, а таксама пераўтварэнне GXT у JSON і JSON назад у GXT.

Беларуская мова падтрымліваецца ўбудаванымі кадзіроўкамі абедзвюх гульняў, у тым
ліку літарамі `Ё/ё`, `І/і` і `Ў/ў`. JSON захоўваецца ў UTF-8 і змяшчае поле
`"language": "be"`; пры імпарце гэта поле выбірае беларускую кадзіроўку GXT без
эурэстычнага вызначэння. Для аўтаматычнага распазнавання ўжо гатовага GTA III GXT
рэкамендуецца пакінуць у назве файла `belarusian` або прэфікс `bel` — сам фармат
GXT не захоўвае моўных метаданых.

## Наступны этап: пара слоўнікаў

Карыстальніцкі інтэрфейс і каманды аддзелены ад сродкаў працы з бінарнымі GXT-файламі.
Для рэжыму перакладу варта дадаць мадэль праекта перакладу, якая супастаўляе запісы
зыходнага і мэтавага GXT паводле ключа і табліцы. `DataGrid` зможа паказваць побач
слупкі «Арыгінал» і «Беларуская», пакідаючы даступным для рэдагавання толькі мэтавы
слупок.
